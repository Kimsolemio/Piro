# 🎙️ AI 실시간 강의록 요약기 (AI Lecture Note Taker)

> **"강의를 듣는 동안, AI가 대신 필기하고 요약합니다."**

이 프로젝트는 별도의 서버 설치 없이 웹 브라우저만으로 동작하는 **실시간 음성 인식 및 AI 요약 도구**입니다.
Google **Gemini API**와 브라우저의 **Web Speech API**를 결합하여, 실시간으로 녹취록을 작성하고 강의가 끝나면 완벽하게 구조화된 강의 노트를 생성합니다.

<br>

*(주의: 원활한 음성 인식을 위해 **PC 크롬(Chrome) 브라우저** 사용을 권장합니다.)*

<br>

## ✨ 주요 기능 (Key Features)

* **1. 실시간 녹취 (Live Transcript)**
    * Web Speech API를 활용하여 음성을 텍스트로 즉시 변환합니다.
    * 오탈자 자동 교정 기능이 포함되어 있습니다.

* **2. 실시간 요약 (Live Summary)**
    * 대화 내용이 일정량 쌓이면 Gemini가 맥락을 파악하여 실시간으로 핵심 내용을 요약합니다.
    * 중요한 내용을 놓치지 않도록 중간중간 요약본을 보여줍니다.

* **3. 최종 강의 노트 생성 (Final Lecture Notes)**
    * 녹음이 종료되면 [주제 - 핵심 요약 - 상세 내용] 구조의 완결된 학습 자료를 생성합니다.
    * 대학원 조교 페르소나가 적용되어 학술적이고 정제된 톤으로 정리됩니다.

* **4. 강력한 편의 기능**
    * **다중 모델 지원:** Gemini 1.5 Flash, 1.5 Pro, 2.0 Flash 등 선택 가능
    * **API 키 로테이션:** 여러 개의 키를 등록하여 사용량 제한(429 Error) 시 자동 전환
    * **파일 내보내기:** 녹취록, 요약본, 최종 노트를 `.txt` 또는 `.doc` 파일로 저장

<br>

## 🛠️ 사용 방법 (How to Use)

1.  **[Google AI Studio](https://aistudio.google.com/app/apikey)**에서 무료 API 키를 발급받습니다.
2.  웹사이트 접속 후 API 키를 입력합니다. (콤마 `,`로 구분하여 여러 개 입력 가능)
3.  사용할 AI 모델을 선택합니다. (기본값: Gemini 2.5 Flash 권장)
4.  **마이크 버튼**을 눌러 녹음을 시작합니다.
5.  강의/회의가 끝나면 정지 버튼을 누르고 잠시 기다리면 **최종 강의 노트**가 생성됩니다.

<br>

## ⚠️ 주의사항 및 트러블슈팅

* **브라우저 호환성:** 이 서비스는 **Google Chrome** 및 Edge 브라우저에 최적화되어 있습니다. (Safari, Firefox에서는 음성 인식 기능이 제한될 수 있습니다.)
* **마이크 권한:** 브라우저 보안 정책상 마이크 사용을 허용해야 작동합니다.
* **모바일 환경:** 모바일에서는 화면 꺼짐 방지 처리가 되어 있지 않아, PC 환경에서의 사용을 권장합니다.

<br>

## 🔒 개인정보 및 보안 (Privacy)

* **Serverless:** 이 프로젝트는 별도의 백엔드 서버가 없습니다.
* **Local Processing:** 입력하신 **API 키**와 **녹음된 음성 데이터**는 오직 사용자의 브라우저 내에서만 처리되며, 외부 서버로 저장되거나 유출되지 않습니다. (API 통신 시 구글 서버로만 전송됨)

<br>
